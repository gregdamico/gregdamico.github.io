Forensic Medicare Auditing & Data Architecture

My work bridges the gap between predictive data science and forensic investigative journalism. Below is a four-phase enterprise architecture designed to map non-linear upcoding behavior and detect administrative latency within the federal healthcare payment system, analyzing both synthetic baselines and 802,000 real-world California CMS claims.

Part 1: The Synthetic Sandbox (Methodology & Baseline)

Before touching real-world federal data, I established my mathematical baselines in a controlled environment. These phases utilize 50,000 synthetic healthcare claims to build, test, and validate both deterministic and glass-box machine learning algorithms.

View Sandbox Repository

Phase 1: Deterministic Anomaly Detection

Python Pandas IQR

Establishing a strict baseline for statistical outliers. Before predicting fraud, an auditing architecture must be able to isolate mathematically undeniable anomalies in billing volume and cost.

  • The Architecture: Built a Python pipeline from scratch to process 50,000 synthetic claims.
  • The Discovery: Applied Interquartile Range (IQR) logic to systematically isolate $3.6M in synthetic Gastroenterology billing waste.
  • The Philosophy: Proving that robust, deterministic thresholds are highly effective before introducing complex machine learning layers.

Phase 2: Glass-Box Machine Learning

InterpretML EBM Glass-Box AI

Rejecting the opacity of "black-box" neural networks. In legal and healthcare auditing, a model that cannot explain its own math is a liability.

  • The Architecture: Implemented an Explainable Boosting Machine (EBM) using Microsoft's open-source InterpretML library.
  • The Philosophy: Advocating for transparent, deterministic "glass-box" models that provide the accuracy of random forests while maintaining exact mathematical interpretability.

Phase 3: Continuous Regression & Non-Linear Upcoding

PyGAM Python 802k Records

Most fraud detection relies on linear thresholds. Phase 3 utilizes Generalized Additive Models (PyGAM) to map the hidden, non-linear curves of Medicare upcoding across 802,000 claims.

  • The Architecture: Engineered a chunked ingestion pipeline to process massive federal datasets without memory crashes.
  • The Output: Generated interpretable partial dependence plots exposing the mathematical inflection points where aggressive billing deviates from standard practice.
Read: The Shape of the Math

Phase 4: Deterministic Audit & Administrative Latency

Pandas DOJ Cross-Reference LEIE Forensics

Transitioning from probabilistic algorithms to binary forensics by executing a strict chronological inner merge between the CMS ledger and the HHS OIG List of Excluded Individuals/Entities (LEIE).

  • The Discovery: Identified anomalous 2024 claims tied to 5 excluded providers, including indictments for fentanyl manufacturing and fake surgical implant schemes (Stivax).
  • The Forensic Insight: Cross-referencing DOJ dockets exposed massive administrative latency (up to 24 months between federal conviction and LEIE exclusion).
  • The Temporal Fog: Documented how the CMS Public Use File's yearly aggregation acts as an accountability shield, making independent chronological auditing mathematically impossible.
